## E. Translation Design
Implemented bidirectional dynamic tool mapping:
1. During connection, discover available tools via MCP tools/list
2. Map AI-OS operation names to actual tool names provided by server
3. Prefer official tool names, fall back to legacy names for backward compatibility
4. Works with both mock server (tests) and real server (production) without modification
