  - Part 01 §1.7.1 defines Core Components as `EventBus`, `ServiceRegistry`, `ConfigurationManager`, `LifecycleManager`.
  - Sets are disjoint except for `EventBus`.
  - This is a CONFLICT preserved per context.md Integrity Rule 3.
