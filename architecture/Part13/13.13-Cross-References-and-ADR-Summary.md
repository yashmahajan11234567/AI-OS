## 2. Cross-Reference Framework

### 2.1 Reference Format

Cross-references in Part 13 follow this format:

- **Section reference**: `[13.X §Y]` for a section in Part 13.X
- **Component reference**: `components.md §Z.Z` for a component specification
- **Schema reference**: `schemas.md §Z.Z` for a schema definition
- **Policy reference**: `policies.md §Z.Z` for a policy definition
- **Event reference**: `governance-events.md §Z.Z` for an event definition
- **Component shorthand**: `G-XX` for governance component X
- **ADR reference**: `[[P13-ADR-XX]]` for an ADR citation

### 2.2 Navigation Conventions

Each Part 13 document includes:

- A header referencing foundational documents.
- A "Cross-References" section at the end linking back to related sections.
- Navigation links to previous and next documents at the bottom.

## 12. Glossary of Governance Terms

| Term | Definition |
|------|------------|
| **Governance Session** | A bounded unit of governance activity initiated by G-00, through which authority is resolved, policies are evaluated, and actions are permitted or denied. |
| **Authority Origin** | The principal from which authority is derived; the root of a delegation chain. |
| **Attestation** | Cryptographic evidence of principal identity, system integrity, or configuration state. |
| **Trust Level** | A tiered classification of trust (Low, Medium, High, Critical) assigned based on attestation evidence. |
| **Governance Invariant** | A condition that must always hold true for the system to be governance-compliant. |
| **Conformance Level** | A maturity tier (L8–L11) measuring governance instrumentation and self-management capabilities. |
| **Audit Trail** | An immutable, tamper-evident record of auditable actions. |
| **Accountability Binding** | The association of an action with an accountable principal. |
| **Delegation Chain** | The sequence of authority transfers from origin to current holder. |
| **Policy Override** | An explicit flag that elevates a policy above others in precedence. |
| **Emergency Authority** | Authority granted during emergencies with automatic expiration. |
| **Governance Body** | A formal decision-making body (council or committee) within the governance structure. |
| **Control Owner** | The principal responsible for a specific governance or security control. |
| **Evidence Chain** | A sequence of evidence items linked to establish a verifiable trail. |
| **Right to Be Forgotten (RTBF)** | The right to have personal data deleted, balanced against audit retention. |
| **Conformance Violation** | A detected failure of a governance invariant. |
| **Control Effectiveness** | The degree to which a control achieves its intended outcome. |
| **Bootstrap Principal** | The initial principal with supreme authority used to establish the governance system. |
| **Governance Namespace** | The `governance.*` event namespace registered in Part 12. |
| **Policy Evaluation Point** | A location where policy evaluation occurs (G-02). |
| **Decision Authority** | The authority to make specific types of decisions. |
